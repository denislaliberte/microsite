## Core Principles

### I. Keep It Simple, Stupid (KISS)
Microsite functionality should be simple and require minimal maintenance; Choose open-source, batteries-included solutions that just work; Avoid complex custom implementations that require ongoing upkeep; Prioritize reliable, well-established tools over cutting-edge alternatives

### II. Text-Based
Use plain text formats (markdown) for future-proofing; Avoid proprietary formats that lock in data; Text files ensure longevity and portability across systems and time

### III. Content-First
Notes and content are the primary focus; UI/UX should enhance readability without distracting; No unnecessary visual elements that don't serve the content; Design decisions prioritize content accessibility and clarity

### IV. Test-First Development
All code must be developed using test-first methodology; Write contract tests before implementation to define expected behavior; Use integration tests to validate end-to-end workflows; Implement unit tests for individual components; No production code without corresponding tests; Tests serve as living documentation of system behavior
